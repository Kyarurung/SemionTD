# 공통 증강 조정

## 변경 내용

| 항목 | 변경 |
|---|---|
| 속전 | 전투 시작 후 8초 동안 최종 피해 +35% → +20% |
| 타워 표기 | 증강 설명의 ‘일반 영구 타워’, ‘일반 영구 공격 타워’를 ‘타워’로 통일. 기존 증강의 적용 대상은 유지 |
| 결전 납품 | 후보, 카탈로그, 구매 계약에서 제거 |
| 일시불 | 매 라운드 첫 적용 가능한 인컴 구매에 자동 발동. 인컴 증가를 포기하고 증가량의 5배를 다이아로 지급 |
| 내실 다지기 | 매 라운드 첫 적용 가능한 인컴 구매에 자동 발동. 체력과 공격력 ×0.7, 인컴 증가량 +40%, 추가 인컴 상한 20 |
| 엄청 이로운 효과 I / II / III | 실버 / 골드 / 프리즘. 타워의 최종 피해, 공격 속도, 최대 체력이 각각 5% / 10% / 15% 증가 |

수치는 소스와 배포용 기본 설정 기준이다. 운영 중인 서버의 저장된 값은 덮어쓰지 않는다.

## 선택과 구매 규칙

- 일시불과 내실 다지기는 동시 보유할 수 없다. 기존의 다른 충돌 제한도 유지한다.
- 엄청 이로운 효과 3종은 같은 계열이다. 한 등급을 선택하면 다른 등급은 후보에서 제외한다.
- 두 자동 인컴 증강은 기존 준비 단계와 구매 대상 조건을 유지한다. 일시불은 인컴 증가가 있는 유료 구매, 내실 다지기는 기존 표준 공격형 인컴에 적용한다.
- 미리보기, 재화 부족, 실패한 구매는 발동 기회를 소모하지 않는다. 성공한 구매에 한 번 적용하고 다음 준비 단계에서 다시 사용할 수 있다. 같은 라운드의 준비 초기화 호출로 횟수를 복구하지 않는다.
- 내실 다지기의 소수 인컴 이월 규칙을 유지한다. 두 번째 구매부터는 일반 수치로 정산한다.
- 일시불과 복제본 생성을 함께 보유하면 첫 구매에 일시불을 적용한다. 켜 둔 복제본 생성 계약은 소모하지 않고 다음 적용 가능한 구매까지 유지한다.
- 일시불과 내실 다지기의 수동 계약 버튼을 제거한다. 이전 구매 버튼으로 자동 발동을 건너뛰거나 재발동할 수 없다.

## 효과와 호환성

- 엄청 이로운 효과는 지정 도구 없이 적용한다. 흑마법사, 엔드와 마왕의 별도 전투 경로도 포함한다.
- 마왕은 본체에 체력과 피해 증가를 적용하고, 마검 공격 충전 간격에 공격 속도를 반영한다. 제단을 거치는 주문에는 피해 증가를 다시 적용하지 않는다. 주문 재사용 대기시간은 바꾸지 않는다.
- 임시 복제본에는 증강을 다시 적용하지 않는다. 승급 시에는 기존 증강 상태 복사 경로를 사용한다.
- 공격 간격은 기존 정수 틱 올림 규칙을 따른다. 짧은 공격 간격에서는 증가율보다 실제 변화가 작을 수 있다.
- 구버전 설정의 결전 납품 항목만 무시한다. 다른 증강의 사용자 설정과 과거 경기 기록은 유지한다.
- 일반 후보는 166종(공통 42종, 직업 전용 124종), 예비 보상 포함 등록 항목은 175개다.

## 검증과 적용 범위

선택 충돌과 재추첨, 설명 및 카탈로그, 구버전 설정, 구매 실패와 중복 정산, 라운드 재발동, 승급과 복제본, 실제 엔티티의 체력·피해·공격 간격을 자동 검사한다.

Java 21에서 `rtk ./gradlew test runGameTest remapJar --console=plain --no-daemon`을 실행했다. 단위 테스트 1,360개 중 1,358개 통과, 2개 제외, 실패 0개다. GameTest 691개가 모두 통과했고 JAR 빌드를 완료했다.

이번 작업은 로컬 구현과 자동 검증 범위다. 운영 배포, 운영 밸런스 변경, 서버 재시작, 커밋 및 푸시는 수행하지 않는다. 실제 클라이언트 화면 확인과 운영 밸런스 평가는 별도다.
