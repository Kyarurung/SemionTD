# PR #95 표시·오라 갱신 수정

작업 브랜치: `codex/pr95-display-aura-fixes`.
기준 커밋: `5baf984e5593e9faadfb0da650a09991b2663312`.

## 변경 내용

- 외형 선택 GUI에서 내부 타워 ID를 제거했다. 외형 선택·저장에 사용하는 ID는 유지한다.
- 편집·설계 목록·타워 설명의 기본 DPS 문구를 같은 함수로 표시한다. 고정 피해의 가격 가중치 1.3은 가격에만 적용하며 표시 DPS에는 곱하지 않는다.
- 모듈 선택 창과 빌더 설명에 실제 모듈 수인 26종을 표시한다. 수치는 enum에서 계산한다. GitHub PR 본문은 변경하지 않았다.
- 개인 타워를 제외하느라 함께 빠지던 빌더 빌더의 웹 카탈로그 항목을 포함하고, 개인 설계는 게임 안의 '내 설계도'에서 확인하도록 안내한다. 개인 타워는 계속 공개 카탈로그에서 제외한다. API 필드·DB 스키마·웹 프런트엔드는 변경하지 않았다.
- 공속·사거리 오라의 sourced `applyTimedEffect` 호출을 기존 `refreshTimedEffect`로 바꿨다. 같은 플레이어의 같은 오라는 합산하지 않고 기존 출처의 수치·지속시간을 갱신한다. 서로 다른 단계의 오라는 갱신 API의 기존 규칙대로 마지막 갱신값을 사용하며, 별도의 최고 단계 우선 정책은 추가하지 않았다.

수정에는 빌더 개발 스킬의 공통 효과 갱신 API와 웹 카탈로그 검증 경로를 사용했다. 새 효과 엔진이나 임의의 밸런스 수치를 추가하지 않았다.

## 검증

Java 21을 사용했다.

- 수정 전: 새 오라 GameTest가 80틱째 효과 소멸을 재현하며 실패했다.
- 수정 후: 같은 플레이어의 오라 제공자 2기로 200틱 동안 공속·사거리 효과가 끊기거나 중첩되지 않음을 확인했다. 갱신을 멈춘 뒤 81틱 내에 두 효과가 만료됨도 확인했다. 단독 실행 1개 통과.
- 표시·카탈로그 집중 JUnit: 27개 통과.
- 전체 JUnit: 총 1,422개 중 1,420개 통과, 기존 2개 skipped, 실패·오류 0.
- `rtk ./gradlew test runGameTest remapJar --console=plain --no-daemon`: 전체 통과 아님. GameTest 713개 중 보류한 P1 재현 검사가 실패했고, 별도의 기존 전투 검사가 실행마다 하나씩 실패했다.
- 전체 실행에서 실패한 기존 검사: `body_game_test_eye_faces_incoming_enemies_at_final_defense`, `developer_game_test_attack_patch_milestone_splashes_nearby_secondaries_with_shared_vfx`. 각각 단독 재실행은 통과했다. 전체 실행에서 발생한 실패의 원인을 확정하거나 해당 테스트를 수정하지 않았다.
- `rtk ./gradlew remapJar --console=plain --no-daemon`: 별도 실행 통과.
- `git diff --check`: 통과.

단독 GameTest는 `JAVA_TOOL_OPTIONS=-Dfabric-api.gametest.filter=<전체 테스트 ID>` 환경에서 실행했으며, 각 실행에서 실제 검사 수가 1개임을 확인했다.

실제 클라이언트 화면과 호스팅된 웹 화면은 이번에 확인하지 않았다. 자동 표시·카탈로그 검사를 화면 검증으로 취급하지 않는다.
